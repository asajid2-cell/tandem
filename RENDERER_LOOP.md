# RENDERER LOOP — autonomous UE5-AAA renderer push

**Overarching goal (broad, fixed):** make CortexEngine a *fully Unreal Engine 5 AAA-quality* real-time renderer.

## Roles (3-tier)
- **Watcher (Claude main / orchestrator — me):** hold the broad goal, keep a heartbeat so the loop never shuts off, check in every iteration. Verify each result at native resolution, commit clean (zero AI attribution), keep this ledger, intervene on failure (revert/redirect). Do NOT micro-spec the work.
- **Lead (Codex, `TANDEM_STATE=lead`, `TANDEM_CWD=CortexEngine`):** the director — acts as the watcher used to. Each turn: review latest renders/state → pick the SINGLE highest-impact next improvement toward UE5 AAA → get it implemented + built + rendered + self-verified → report. One focused improvement per turn. Revert anything that regresses. Does NOT git commit (watcher commits).
- **Helper (Claude, driven BY Codex via `node bin/peer.mjs ask -` from the tandem dir):** the implementer the Lead delegates heavy edits to. Lead may also implement directly.

## Loop protocol (one iteration)
1. Watcher dispatches the Lead (background) for ONE improvement.
2. Lead picks + implements + builds + renders + self-verifies, reports (no commit).
3. On Lead completion (or heartbeat), Watcher: views the render at native res → if a real, regression-free win, `git commit` clean; else revert/redirect.
4. Watcher appends the result below, dispatches the next iteration, reschedules the heartbeat.

## Heartbeat
- Primary wake: background-task completion of the Lead turn.
- Safety net: ScheduleWakeup ~1500s fallback in case a turn hangs.

## Build/verify
- Build: `powershell -File rebuild.ps1 -Config Release` (C1060 = retry).
- Render: `tools/render_scene.ps1 -Prompt "..." -OutName x` / `-Scene beach`. Showcase: `tools/render_showcase.ps1 -OutName x`.
- Git root: `graphics/` (branch `cleanup/debt-artifacts`). Clean commits, no AI attribution.
